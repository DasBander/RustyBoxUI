# Radio guide photograph

The receiver guide uses a cropped WebP version of *The Goldstone Solar System Radar at Sunset* (PIA26150). Credit NASA/JPL-Caltech. [Original photograph and credit](https://science.nasa.gov/photojournal/the-goldstone-solar-system-radar-at-sunset/)

The game banners, covers and fonts are shared with the RustyBox storefront. The repository and SDK include their credits in `ui/art/CREDITS.md`. The standalone library also includes them in `steam-ui/art/CREDITS.md`.
